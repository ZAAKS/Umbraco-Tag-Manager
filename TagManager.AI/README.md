# TagManager.AI

Optional **Create with AI** action for the built-in Umbraco Tags editor.

Install this package only when the site already has [Umbraco.AI](https://www.nuget.org/packages/Umbraco.AI). Tag Manager itself does not depend on Umbraco.AI.

## Requirements

- Umbraco CMS 17.5 or newer, up to Umbraco 17
- Umbraco.AI 17.7 or newer
- A configured Umbraco.AI connection and default profile

## What it does

On a Tags property, **Create with AI** asks how many tags to suggest, then adds the suggestions to the field. Save the content as usual.
